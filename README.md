# Cinetix — Cinema Ticket Booking Kiosk

A modern, high-performance self-service Cinema Ticketing Kiosk application built for high-throughput public displays and web interfaces.

## Features

- **Attract Screen**: Dynamic video/poster looping carousel with red accent animations.
- **Language & Movie Browsing**: Instant movie filtering by format (IMAX, 3D, 4DX, Standard) and genre.
- **Showtime & Seat Selection**: Interactive screen layout grid supporting Gold/Silver tiers & accessible seating.
- **Add-on Concessions**: Quick popcorn, drinks, and combo selection with dynamic cart calculation.
- **Payment Gateway Simulation**: Contact entry, UPI QR code scanning, and card payment flows.
- **Kiosk Idle Timeout & Stepper Navigation**: Automatic session reset for kiosk operation.

## Tech Stack

- **Framework**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS + Framer Motion
- **UI Components**: Radix UI / shadcn-ui primitives + Lucide React icons
- **State & Data**: TanStack React Query

## Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- npm / bun

### Installation & Running Locally

```bash
# Install dependencies
npm install

# Run dev server
npm run dev

# Build for production
npm run build
```
